# What only jass can supply

Type: task (HITL)
Status: open — a standing queue, claimable by jass any time, in any order
Blocks: 16 (the marginalia half)

## Question

None — this is the one ticket that does rather than decides. It is the
standing queue of inputs that only jass can produce, because the copy rule
has no exception and taste calls are his. Each item unblocks work the moment
it lands; none of them block each other.

## The queue

1. **`SOURCE_NOTE`** (`src/intro.ts`) — the View Source comment. Plumbed and
   shipping zero bytes until filled. Constraints on the constant: deadpan,
   nothing explaining it, no `--` inside.
2. **Marginalia pairs** — (word in the intro, meme) — the word is voice, the
   meme is taste. Two is probably the right number for the whole intro;
   ticket 16 builds them.
3. **The footer's words** (ticket 19 decides placement): the 2am murmur, and
   the copyright joke if it earns the slot.
4. **A console line?** Optional — the friend now has JS, so the friend could
   have one line in devtools. Only if a line occurs to him; an empty console
   is better than a strained one.
5. **The OG re-shoot** — the old card was a photograph of a screen, which was
   a better idea than the generated wordmark card. Only he can retake it.
   (Also: preview OG testing is blocked on him disabling Vercel deployment
   protection for previews, or minting a share link.)

## Done when

Never, formally — items get struck as they land, and new copy slots get
appended here instead of scattered across tickets.
